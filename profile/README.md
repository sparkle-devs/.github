# Sparkle
<img width=512 height=128 src=banner.png>

> [!IMPORTANT]
> Sparkle is still in heavy development and will change constantly! However, we still invite you to help with development, bug test, and make mods.


Sparkle is a modding framework for Snap! that provide a streamlined ways for addons (glorified userscripts, thats all) to modify Snap! and most importantly, mostly not break with eachother.

Made by [@tethrarxitet](https://forum.snap.berkeley.edu/u/tethrarxitet), [@codingisfun2831t](https://forum.snap.berkeley.edu/u/codingisfun2831t), [@e016](https://forum.snap.berkeley.edu/u/d016), and [@PPPDUD](https://www.github.com/PPPDUD) among others.

Read more on [Sparkle's](https://github.com/sparkle-devs/sparkle) README!
