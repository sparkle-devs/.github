# Sparkle
<img width=512 height=128 src=banner.png>


Sparkle is a modding framework for the Snap! programming language.

Sparkle is made possible by [@tethrarxitet](https://forum.snap.berkeley.edu/u/tethrarxitet), [@codingisfun2831t](https://forum.snap.berkeley.edu/u/codingisfun2831t), [@e016](https://forum.snap.berkeley.edu/u/d016), and [@PPPDUD](https://www.github.com/PPPDUD) among others.

Read more at [Sparkle's GitHub repository](https://github.com/sparkle-devs/sparkle)!
